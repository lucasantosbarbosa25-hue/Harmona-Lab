      Oitavas, DAW e formato das notas

      Como escrever notas. Letra + acidente + oitava: C4, F#2, Eb3, Bb3, C##4. Também vale o número MIDI (60). Separe por espaço, vírgula ou travessão: F#2 – C3.

      Convenção de oitava. Internamente tudo é número MIDI. Por padrão, MIDI 60 = C4 (dó central, padrão científico). Ableton Live e Studio One costumam chamar essa mesma tecla de C3: é a mesma nota, só muda o nome. Se preferir ver os nomes como na sua DAW, troque “Dó central” para C3 — as teclas exportadas continuam idênticas.

      Na DAW. Arraste o .mid para uma faixa de instrumento. Algumas DAWs não trocam o BPM do projeto ao importar: as notas já estão em tempos musicais, então ficam certas em compassos; ajuste o BPM do projeto se quiser o andamento do arquivo.

      O nome do acorde é só um rótulo. O MIDI usa exatamente as notas digitadas. O nome vai como marcador no arquivo.
